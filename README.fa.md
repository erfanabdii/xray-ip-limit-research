# راهنمای فارسی

این مخزن، گزارش تحقیق، داده‌های منتخب و patchهای آزمایشی محدودیت IP برای
Xray و پنل را نگه می‌دارد. قابلیت روی سرویس واقعی فعال نشده است.

## نتیجهٔ اصلی

محدودیت مورد بررسی، «تعداد IP فعال برای هر حساب» است؛ تعداد دستگاه نیست.
هدف این است که IP اضافه فقط برای همان حساب رد شود. ثبت IP در پنل و اجرای
درست بن پشت CDN دو موضوع متفاوت‌اند.

- **نسخهٔ Go:** پذیرش IP را داخل Xray بررسی می‌کند؛ نمونهٔ آزمایش‌شده تک‌نودی است.
- **نسخهٔ Lua + کنترل‌کننده:** با هستهٔ رسمی کار کرد و دو core روی یک میزبان
  را هماهنگ کرد؛ این آزمایش، اثبات هماهنگی دو سرور در دو کشور نیست.
- در بار یکسانِ پاس ۵، میانگین زمان CPU نسخهٔ رسمی حدود ۹۷٫۸، Go حدود ۱۰۳٫۱
  و Lua کامل حدود ۱۵۹٫۳ میلی‌ثانیه بود. این عددها افزایش درصدی CPU کل VPS
  یا هزینهٔ ثابت هر کاربر نیستند؛ فقط به همان بار و شرایط آزمایش مربوط‌اند.
- آزادشدن ظرفیت به پایان تشخیص‌داده‌شدهٔ جریان وابسته است. تأخیر حدود دو
  ثانیه در نمونهٔ محلی با تایمرهای پایان جریان توضیح داده شد. صفرکردن آن‌ها
  در تست half-close پاسخ معتبر را از دست داد.

## به چه چیزهایی هنوز نرسیده‌ایم؟

شروع بدون policy معتبر، اختلاف parser پنل و core، حفظ مالکیت محدودکننده
هنگام آپدیت، کنترل ظرفیت از پنل و هماهنگی عملیاتی چندنودی هنوز ایراد یا
کار باز دارند. نمونه آمادهٔ نصب عادی یا استفادهٔ عملیاتی اعلام نشده است.
تست‌های موفقی که یک ایراد را بازتولید می‌کنند، به معنی رفع آن ایراد نیستند.
